# 生活記帳 Living Expenses

一個免安裝、免後端的生活開銷記帳 App（PWA），可在手機加入主畫面當 App 使用，也可離線使用。

## 功能

- **分類記帳**：支出／收入兩種類型，內建常用分類（餐飲、交通、購物、居住、薪資、獎金…），可輸入金額、日期、備註；點選紀錄可編輯或刪除。
- **記帳明細**：依月份瀏覽，按日分組並顯示每日小計；可依類型、分類篩選，搜尋備註。
- **分類統計**：環形圖＋排行清單，顯示各分類金額、占比、筆數，支出與收入可切換。
- **綜合統計**：總收入、總支出、結餘、日均支出、儲蓄率，以及每日／每月收支長條圖。
- **期間選擇**：月、年、全部、自訂日期區間。
- **分類管理（手動增加／刪除）**：
  - 記帳時直接在分類區點「＋ 新增分類」，輸入圖示、名稱、顏色即可新增並自動選取。
  - 點「編輯分類」後，點任一分類即可刪除（既有紀錄自動移到「其他」），點「完成」結束。
  - 「設定 → 分類管理」也可新增、重新命名、排序、刪除。
- **資料**：匯出 CSV（Excel 可直接開啟）、JSON 備份／還原、清除全部。
- 支援深色模式。

## 使用方式

純靜態網頁，不需建置：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

也可部署到 GitHub Pages 等任何靜態主機，手機瀏覽器開啟後選「加入主畫面」即可。

> 資料儲存在瀏覽器的 localStorage，只存在該裝置上，請定期使用「備份資料」。
